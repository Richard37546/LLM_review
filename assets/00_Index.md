# 00 Index｜从哪里开始读？

## 你现在应该记住什么
1) 你不需要一次学完全部：每天只读 1 页，并做自测题即可。  
2) 学 LLM 最容易迷路的点是“术语太多”：本仓库每个术语第一次出现都会解释。  
3) 如果你只想快速建立“推理性能”直觉，先读 **Prefill/Decode → KV Cache** 两页。
