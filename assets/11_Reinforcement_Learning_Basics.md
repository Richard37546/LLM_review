# 11 Reinforcement Learning Basics｜强化学习基础

## 你现在应该记住什么
1) 强化学习（RL）是在与环境不断交互的过程中，通过奖励信号学习决策策略，目标是最大化长期累计回报。  
2) 它和监督学习最大的不同是：监督学习通常有直接标签；强化学习通常没有标准答案，只有好坏反馈。  
3) RL 最核心的对象是：agent、environment、state、action、reward、policy。  
4) policy 是“怎么做决策”，value 是“这个状态/动作到底有多值”；reward 是单步反馈，不等于长期价值。  
5) RL 的典型难点包括：延迟奖励、探索与利用、信用分配、奖励设计。

---

## 专有名词解释
- **Agent（智能体）**：做决策的主体。  
- **Environment（环境）**：智能体交互的外部世界。  
- **State（状态）**：当前局面的描述。  
- **Action（动作）**：智能体在某个状态下采取的行为。  
- **Reward（奖励）**：环境对动作结果给出的反馈分数。  
- **Policy（策略）**：在不同状态下如何选择动作的规则，常记作 \(\pi(a|s)\)。  
- **Return（回报）**：从当前开始未来累计获得的总奖励。  
- **Value（价值）**：对未来长期收益的估计。  
- **Q Value / Action Value**：某状态下执行某动作后，未来累计收益的估计。  
- **Trajectory（轨迹）**：状态、动作、奖励连起来形成的一整段交互过程。  
- **MDP（Markov Decision Process）**：描述序列决策问题的标准数学框架。

---

## 为什么会有强化学习
监督学习很适合这种问题：

- 有明确输入  
- 有明确输出  
- 有明确标准答案

例如：
- 图像分类  
- 文本分类  
- 机器翻译  
- 命名实体识别

但有些问题不是这样：

- 下围棋  
- 自动驾驶  
- 机器人控制  
- 游戏智能体  
- LLM 生成整段文本

这些问题通常有三个特点：

1) **不是一步决策，而是连续决策**  
2) **当前动作的好坏，未必立刻知道**  
3) **没有唯一标准答案**

这就需要一种靠“试错 + 反馈”来学决策的方法，这就是强化学习。

---

## 强化学习最基本的六个对象

### 1. Agent
智能体，也就是做决策的人/模型/系统。

例如：
- 下棋程序  
- 自动驾驶系统  
- 机器人  
- 对话模型

### 2. Environment
环境是智能体所在的世界，它会对动作作出反馈。

例如：
- 围棋棋盘  
- 游戏环境  
- 物理世界  
- 用户偏好反馈系统

### 3. State
状态表示“当前局面是什么样”。

例如：
- 当前棋盘  
- 当前机器人位置和速度  
- 当前对话上下文  
- 当前已生成的 token 前缀

### 4. Action
动作表示“当前这一步要做什么”。

例如：
- 下哪一步棋  
- 机器人向左转  
- 汽车加速  
- 语言模型生成下一个 token

### 5. Reward
奖励是环境对行为结果的反馈。

例如：
- 赢棋 +1，输棋 -1  
- 到达目标 +10  
- 跌倒 -100  
- 更符合人类偏好的回答获得更高分

### 6. Policy
策略就是决策规则：

\[
\pi(a|s)
\]

表示在状态 \(s\) 下，采取动作 \(a\) 的概率。

你可以把它理解成：
> 智能体的大脑 / 决策函数。

---

## Return：为什么 RL 关心长期而不是眼前
强化学习通常不是只看“这一步拿了多少奖励”，而是看：

> 从现在开始，未来总共能拿多少回报。

常写成：

\[
G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots
\]

这里：
- \(r_t\)：第 \(t\) 步奖励  
- \(\gamma\)：折扣因子，表示未来奖励的重要程度

### 为什么要有折扣因子
因为通常：
- 眼前奖励更确定  
- 很久以后的奖励更不确定

所以未来奖励会被打折。

---

## RL 和监督学习的本质区别
### 监督学习
- 有固定数据集  
- 有明确标签  
- 目标是拟合标签

### 强化学习
- 没有直接标签  
- 要和环境交互  
- 只有奖励信号  
- 目标是最大化长期累计回报

一句话总结：

> 监督学习是在“已知正确答案”的数据上做映射拟合；强化学习是在“没有直接标准答案”的交互环境中，通过奖励学习长期决策策略。

## State Value 和 Q Value 是什么
### 1. State Value：\(V(s)\)
表示：

> 如果我现在处于状态 \(s\)，并且之后都按当前策略走，长期能拿到多少回报。

它在评价：
> 这个状态整体值不值。

### 2. Action Value：\(Q(s,a)\)
表示：

> 在状态 \(s\) 下，先采取动作 \(a\)，之后再按当前策略走，长期能拿到多少回报。

它在评价：
> 在这个状态下，这个动作值不值。

### 最重要的区别
- \(V(s)\)：评价状态  
- \(Q(s,a)\)：评价状态下的动作

---

## Policy 和 Value 的关系
- **Policy**：告诉你“现在该做什么”  
- **Value**：告诉你“当前状态或动作到底有多好”

所以你可以理解成：
- policy 是 **决策器**  
- value 是 **评估器**

很多 RL 算法本质上都是：
1) 先评估  
2) 再据此改进策略

---

## 强化学习为什么难
### 1. 延迟奖励（Delayed Reward）
当前动作的真正效果，可能要过很多步才能体现。

### 2. 信用分配问题（Credit Assignment）
最终拿到好结果，到底该归功于前面哪些动作？

### 3. 探索与利用（Exploration vs Exploitation）
- 利用：选择当前已知最优动作  
- 探索：尝试可能更好的新动作

这两者必须平衡。

### 4. 奖励设计困难
如果奖励设计不好，模型可能学会钻空子，而不是真正完成任务。

---

## 什么是 MDP
MDP（马尔可夫决策过程）是强化学习中描述序列决策问题的标准框架，通常包含：

- 状态空间 \(S\)  
- 动作空间 \(A\)  
- 状态转移规则  
- 奖励函数  
- 折扣因子 \(\gamma\)

### 什么叫马尔可夫性
你可以先记成人话：

> 未来只和当前状态有关，而和更久之前的历史无关。

也就是说，当前状态已经足够概括过去的重要信息。

---

## RL 在大模型里怎么对应
在 LLM 场景里，可以这样映射：

- **state**：当前 prompt + 已生成文本  
- **action**：下一个 token 的选择  
- **policy**：模型对下一个 token 的概率分布  
- **trajectory**：整段生成过程  
- **reward**：这段回答最终得到的评价分数

这也是为什么后面 RL 能用在 RLHF 上。

---

## 常见误区
1) 以为强化学习就是“有奖励的监督学习”：不对，监督学习有标签，RL 通常没有。  
2) 以为 reward 就等于 value：reward 是单步反馈，value 是长期收益估计。  
3) 以为当前奖励高就一定是好策略：RL 优化的是长期累计回报。  
4) 以为 policy 和 value 是一回事：policy 负责决策，value 负责评估。  
5) 以为 PPO 就是强化学习本身：PPO 只是 RL 的一个具体算法。
